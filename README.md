mend applies edits AI models write — unified diffs (often with wrong line numbers), SEARCH/REPLACE blocks, V4A patches, and JSON text-editor tool calls — to a tree of text files. It finds target lines even when whitespace and indentation drifted, and every file changes or nothing does.

## Run it

```sh
node main.ts [--format=NAME] [--check] [--strict] [PATCH]
```
